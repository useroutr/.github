Useroutr

A lowercase u whose left arm arrives as detached orange dots and leaves as one unbroken stroke. What the user brings comes in pieces, in the signal colour; what the application receives is single and settled.

Two cuts, pick one

One dot

Dot radius 4, stub 8. The quieter of the two. Reads as a letterform first and a diagram second, and the single node holds its weight against the stroke.

Two dots

Dot radius 3, even 3-unit rhythm, stub 6. Says many rather than one, which is closer to the thesis. Costs a little at 16 pixels, where the two dots start to merge.

Identical construction: same bowl, same output stroke, same orange. They differ only in how much of the left arm is spent on dots rather than stub. The sections below apply to whichever is chosen.

How the mark is built

The dot is the input

Detached, and the only element in colour. Whatever the user holds, on whatever rail. Radius four against a stroke of six, so it reads as a node rather than a fragment of the letter.

The stub anchors the arm

Eight units, and structurally not optional. Without it the bowl becomes a hook and the whole mark reads as a j.

One stroke leaves

A true semicircle of radius twelve rising into an unbroken vertical. The settled output, credited once.

Lockup

useroutr

Set lowercase, to rhyme with the mark. The optical gap between mark and word equals the stroke weight. The mark is never used as the letter u inside the word: at text size the dot collapses onto the arm and the idea disappears.

The orange belongs to the dot. It lifts to #FF7433 on dark ground so it holds the same optical weight rather than going muddy. Ink carries a slight blue bias and paper a slight warm one, so neither reads as default black or default white. Use orange for the dot and at most one control per screen; it is a signal, not a wash.

Rules

Do

Keep clear space of one bowl radius, twelve grid units, on every side.

Do

Lift the orange to #FF7433 on dark grounds.

Do

Use the mono cut wherever the orange cannot reproduce.

Don't

Remove the stub or lengthen it to a full arm. Eight units, exactly. Shorter and the mark becomes a j; longer and the dot stops reading as detached.

Don't

Colour the bowl or the output stroke. Only the dot is orange.

Don't

Rotate or mirror it. The direction is the meaning: input on the left, settled output on the right.

Generation prompt

For running against an image model. The mark was drawn as vector rather than generated, so treat this as a way to explore adjacent directions, not to reproduce it.

Minimalist vector logo mark for "Useroutr", a payments infrastructure
company. A single lowercase letter "u" built from one geometric stroke
of uniform weight with rounded terminals. The left arm is reduced to a
short stub with a separate circular dot floating above it in bright
orange; the bowl sweeps right and rises into one unbroken vertical
stroke in near-black. The idea: a detached input resolving into a
single settled output. Two colours only, orange dot on near-black
letterform, warm off-white background. Flat, no gradient, centred,
generous margin, optically balanced. Swiss International Typographic
Style, transit-signage precision, Vignelli. Vector, SVG-ready,
legible at 16 pixels.

Negative: gradient, shadow, bevel, 3D, glow, texture, photorealism,
mascot, globe, arrow, coin, chain link, hexagon, shield, swoosh,
serif, script, badge, emblem, ribbon, background scene, watermark,
text, lettering beyond the single "u", letter j, hook shape.

Production notes

The letterform uses currentColor and the dot is a fixed hex, so the mark inherits the ground from CSS while the orange stays constant. No per-theme copies.

The wordmark on this sheet is set in the system UI face as a placeholder. Before launch it should be set in a licensed geometric or neo-grotesque with a single-storey a and converted to outlines, so it never depends on a font being present. Faces worth trialling: Söhne, Diatype, Aeonik, Suisse Int'l.

Files sit in brand/. One dot: useroutr-mark.svg, useroutr-mark-mono.svg, useroutr-favicon.svg. Two dots: useroutr-mark-two-dot.svg, useroutr-mark-two-dot-mono.svg, useroutr-favicon-two-dot.svg. Once a cut is chosen, the other set should be deleted rather than left around to drift into use.
